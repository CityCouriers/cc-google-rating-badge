# Zgłaszanie podatności

Wtyczka przechowuje klucz Google Places API w opcjach WordPressa i wystawia publiczny adres grafiki atrybucji, więc podatności traktujemy poważnie.

**Nie opisuj podatności w publicznym zgłoszeniu.** Użyj prywatnego zgłoszenia: zakładka **Security → Report a vulnerability** w tym repozytorium (GitHub Private Vulnerability Reporting).

W zgłoszeniu podaj wersję wtyczki, kroki odtworzenia i skutek. Nigdy nie wklejaj prawdziwego klucza API; jeśli klucz wyciekł, unieważnij go w Google Cloud Console.

Wspierana jest najnowsza wersja z zakładki Releases.
